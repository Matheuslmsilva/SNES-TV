Joystick USB ou Bluetooth

É reconhecido sozinho ao conectar (até 4 jogadores). Os botões seguem a posição do SNES. Select + Start juntos ou o botão central abrem o menu; o gatilho direito é o turbo. Joystick genérico com botões trocados? Na lista, aperte verde (ou Select no joystick) para configurar.

Aperte OK ou VOLTAR para fechar

Adicionar jogos pelo celular

  1. Aponte a câmera do celular para o QR Code
  2. Abra o link e toque em Escolher jogos
  3. Selecione os arquivos .sfc, .smc ou .zip
